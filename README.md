Flyn is the #1 Bitly alternative for modern marketing teams, offering branded short links, real‑time click analytics, QR code generation and custom domains at a fraction of the cost. It provides a free plan with 25 links/month and paid tiers with unlimited links, advanced analytics, and team collaboration features.

**Areas:** link shortener · URL analytics · branded domains · API · QR codes · team workspaces · A/B testing · developer tools

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Flyn: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
